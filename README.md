# Calculator Master

**Student Name:** Allan Joseph A. Martisano
**Section:** BIT41

## Project Description
A menu-driven Python calculator built using Git and GitHub branching. Each arithmetic operation was developed on its own feature branch and merged into main via pull requests.

## Branch Structure
- `addition_Martisano`
- `subtraction_Martisano`
- `multiplication_Martisano`
- `division_Martisano`

## Program Features
- Menu-driven interface accepting numbers, letters, or full words
- Input validation
- Division-by-zero handling
- Continuous execution until exit
